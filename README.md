# Amaterasu — Información y Política de Privacidad

Este repositorio aloja la página principal pública y la política de privacidad oficial de **Amaterasu**, una herramienta privada de gestión y automatización multimedia para Google Drive.

## Contenido
- `index.html`: Página de inicio pública de la aplicación.
- `privacy.html`: Declaración de privacidad conforme a las políticas de datos de usuario de las API de Google (Google API Services User Data Policy) y requisitos de Uso Limitado (Limited Use Disclosure).

## Cumplimiento de Políticas de Google
Amaterasu solicita acceso estrictamente de solo lectura (`drive.readonly`) para la inspección y descarga de medios personales autorizados por el usuario, sin modificar ni compartir información con terceros.
